# 원리 참고

아래 자료는 일반 원리와 용어 확인에 사용했습니다. 도면·제품 사진·CAD·상표 자산을 앱에 복제하지 않았습니다. 앱의 고정 수치와 3구간 정류자 기하는 특정 제조사 제품을 재현하지 않습니다.

- University of Michigan CTMS, [DC Motor Position: Simulink Modeling](https://ctms.engin.umich.edu/CTMS/?example=MotorPosition&section=SimulinkModeling): 전기 회로와 회전 운동의 결합, 일관된 SI에서 토크·역기전력 상수의 관계.
- maxon, [Motor data and simulation](https://support.maxongroup.com/hc/en-us/articles/360013761160-Motor-data-and-simulation): 모터 특성·토크 상수·속도와 토크의 용어. 앱은 해당 제품의 실제 상수를 사용하지 않습니다.
- maxon, [Motors as Generators](https://support.maxongroup.com/hc/en-us/articles/360004496254-maxon-Motors-as-Generators): 회전에 따른 발생 전압과 발전기 사용 원리. 앱의 0 V 단락·음의 전류 해석은 채택한 평균 등가회로의 결과입니다.
