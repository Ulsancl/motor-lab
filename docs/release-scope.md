# 완성 기준과 한계

이 문서는 Motor Lab 1.0의 유한한 완성 기준입니다. 실제 검사·설치·업데이트·공개 결과는 각 릴리스의 결과 기록을 따릅니다. 이 기준을 정한 것만으로 완료를 주장하지 않습니다.

- 평균 RL·회전 운동·에너지 계산이 독립 식과 시간 분할 검사를 통과한다.
- 32개 부품, 고정 브러시·회전 정류자와 권선 연결이 공통 기하 계약을 따른다.
- 권선·절연 레이어 이름은 실제 보이는 범위와 일치하며, 단자·정류자 부품을 선택한 뒤 시점을 맞추면 선택한 구조와 이름을 확인할 수 있다. 시점 이동을 명시적으로 요청한 경우 화면이 3D 관찰 영역으로 이동한다.
- 세 실험에서 실제 설정·모형 상태와 같은 수치를 표시한다. 그래프와 비교 자료의 시간·단위를 명시한다.
- 안내의 다음 재생 행동을 화면에서 찾을 수 있고, 일시적인 알림이 관찰과 조작을 지속적으로 막지 않는다.
- 원문을 지키는 strict 저장·복원과 동일 상태 이후 계속 계산을 확인한다.
- 실제 브라우저와 Windows 앱에서 재생·관찰·카메라·파일·복구·창 복원 및 좁은 화면 접근성을 확인한다.
- 실제 설치 파일의 소스·라이선스 정합성, 최초 설치와 업데이트 경로를 배포 전에 별도로 확인한다. 제거 프로그램의 포함 여부와 사용자 데이터 삭제 설정은 정적으로 확인하며, 이를 실제 제거 동작을 시험한 결과로 표현하지 않는다.

이 범위는 권선별 전자기 해석, 열·아크·소음·마모·PWM·자속 포화·기기 수명·실제 안전성을 포함하지 않습니다. 3구간 정류자와 3권선 연결은 설명용 기하이며 실제 제품 복제물이 아닙니다. 속도에 비례하는 부하 계수만 다루며 특정 제조사 모터나 팬 성능을 보장하지 않습니다. 외부 초보 사용자 연구, 판매 전환, 유료 지원 또는 모든 GPU·운영체제 호환성을 검증했다는 주장을 하지 않습니다.
