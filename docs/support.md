# 문제 보고

공개 저장소의 오류 신고 양식으로 앱 버전, Windows 버전·화면 배율·GPU, 재현 순서와 기대한 결과를 알려 주세요. 가능하면 개인 정보가 없는 최소 실험 JSON을 첨부하세요. 손상 원문은 별도로 보관하고 반복 저장으로 덮어쓰지 마세요. 지원 응답 시간·유료 유지보수·실제 장비 사용 적합성을 약속하지 않습니다.

화면이 잘리면 전체 보기로 시점을 맞추고, 회전이 너무 빠르면 관찰 배율을 낮추세요. 그래도 남는 문제는 정상·오류 상태를 구분해 기록합니다. 개발 검사 로그의 개인 경로나 장치 식별자를 공개할 필요는 없습니다. 파일 이름·비교 이름·스크린샷에 개인 정보가 있는지 확인해 주세요. 설치 파일은 해당 저장소의 릴리스에서 버전과 SHA-256을 확인한 뒤 사용하세요.
