# Motor Lab 1.1 상세 개선 범위

2026-10-02 · 개선 브랜치의 구현 범위. 공개 설치 파일의 배포 여부와 검증 결과는 해당 GitHub 릴리스를 따른다.

이번 상세 관찰은 기존 `motor-dc-average-1` 평균 DC 모형이 이미 푼 상태를 부품과 연결한다. 계산 상수·시간 적분·저장 스키마를 바꾸거나 기존 실험·비교 기록에 필드를 끼워 넣지 않는다.

## 관찰할 수 있는 것

- 전원·단자·리드: 적용 전압, 부호 있는 평균 단자 전류와 공급 동력, 저항·역기전력·인덕턴스 전압의 분해.
- 전기자·축·커플링: 현재 회전수·각가속도, 전자기·점성 마찰·외부 부하의 부호 있는 토크, 전체 등가 관성의 회전 저장량과 변화율.
- 시험 부하: 실제 적용된 속도 비례 계수, 저항 토크, 흡수 동력·누적 에너지, 같은 조건을 유지할 때의 평형 회전수.
- 권선: 실제 연결된 정류자 편과 전체 전기자의 R/L·평균 전류·구리 손실·자기 저장 에너지. 전체 값을 권선별 계산값으로 표시하지 않는다.
- 브러시·정류자: 실제 편 각구간과 브러시 각구간의 교집합, 절연 간극을 뺀 곡면 접촉 면적, 표면 속도, 브러시 하나당 편 통과 빈도.
- 자석·하우징·엔드벨: 공유 기하의 치수와 고정 모터 상수의 구분. 대표 공극을 실제 자속 밀도나 토크 상수의 해석 결과로 표현하지 않는다.
- 베어링: 장면과 같은 helper로 구한 내륜·외륜·케이지·볼의 순간 회전수. 외륜 고정·접촉각 0·미끄럼 없음이며 볼 자전은 고정 좌표 기준이다. 하중·마찰·수명·온도는 계산하지 않는다.
- 시험대·고정 구조: 개별 전기/기계 저장 변화와 전력 수지, 고정축 실험의 구속반력. 브래킷 응력과 지지점별 반력은 제공하지 않는다.

`motorDetail`은 SI 숫자를, `describeMotorDetail`은 부품당 최대 6개 표시값과 한계 설명을 반환한다. 입력 state와 선택적으로 전달한 동일 상태의 snapshot을 수정하지 않는다. 현재 입력란의 초안과 화면 재생 배율은 상세 계산에 영향을 주지 않는다.

## 부호와 한계

전압 항은 `V = Ri + Keω + Ldi/dt`, 토크 항은 `Jα = Kti − bω − bLω + 구속반력`을 따른다. 음의 회생 전류·공급 동력, 역방향 회전에서 양수가 되는 저항 토크를 그대로 유지한다. 0 V 단락에서 공급은 0 W여도 전류와 구리 손실은 남을 수 있다.

공급은 구리·마찰·부하와 두 저장 변화의 합이다. 전자기 변환 동력은 내부 전달이므로 그 합에 중복으로 넣지 않는다. 고정축 기동에는 자기 저장 증가가 있으므로 순간 공급 전체가 항상 구리 손실인 것은 아니다. 손실·흡수 에너지로 부품 온도를 만들거나 과도 중 동력비를 효율로 표시하지 않는다.

평형 참조는 현재 설정을 유지할 때의 회로·토크 균형이다. 현재 상태를 대체하지 않고, 평형 도달 시간·정격·열 한계를 주장하지 않는다. 기하 접촉은 코일별 순간 전류나 정류 맥동을 추가하는 전기 회로 해석이 아니다.

저장 파일의 모터 각도에는 누적 회전수가 없다. 따라서 베어링의 시각적 위상은 실제 진행 구간의 전체 회전량으로 누적하고 복원 시 관찰 기준을 새로 잡는다. 상세 출력은 순간 회전수만 제공하며 저장 스키마에 베어링 위상을 추가하지 않는다.

## 확인 방법

추가 순수 검증은 독립 RL 식과 유한차분, 부호 있는 토크·전압·저장량 수지, 긴 시간 해와 평형 참조, 브러시 접촉 경계와 한 바퀴 면적 평균, 32개 부품의 유한 표시값과 원본 불변성을 검사한다. 접촉 면적의 회전 평균은 명목 브러시 면적에 구리 점유율 118°/120°를 곱한 값과 일치한다. 실제 브라우저·GPU·설치 검증은 별도 검사다.
