# Windows 앱

대상은 Windows 11 x64입니다. `npm run package:desktop`은 `release/windows/Motor-Lab-Setup-1.0.0.exe`와 `.sha256`을 생성하며 자동 게시하지 않습니다. 이름의 버전은 package.json을 따릅니다. 실제 설치·하드웨어 검증 환경은 각 릴리스의 결과 기록을 확인하세요. 개발 중 실제 하드웨어 관찰은 NVIDIA GeForce RTX 5080·화면 배율 150% 환경에 한정되어 있으며 다른 GPU·원격 접속 환경까지 보장하지 않습니다.

앱 이름은 Motor Lab, ID는 `com.motorlab.app`, 로컬 화면 주소는 `app://motor/`입니다. 사용자 프로필은 Windows 앱 데이터 폴더의 Motor Lab입니다. 도움말의 저장 폴더 열기에서 접근합니다. 네이티브 창 크기·위치를 보관하고 작업 영역 밖으로 나간 창은 사용 가능한 화면 안으로 복원합니다.

파일 메뉴에서 새 실험·열기·저장을 수행하고 실험 메뉴에서 재생을 바꿉니다. 보기의 3D 크게 보기, 도움말의 사용 안내와 프로그램 정보를 사용할 수 있습니다. 파일 대화상자나 자료 처리가 진행 중이면 종료 확인을 표시합니다. 원문 복구 다운로드는 검증된 새 실험 저장과 별개로 원문 바이트를 보관합니다.

앱은 코드 서명되지 않아 Windows의 게시자·평판 경고가 표시될 수 있습니다. 자동 업데이트는 없습니다. 파일을 보관하고 앱을 닫은 뒤 새 설치 파일을 실행합니다. 설치 앱 실행에는 Node.js·개발 서버가 필요하지 않습니다. 제거 설정은 실험을 보호하기 위해 사용자 앱 데이터를 자동 삭제하지 않도록 구성했습니다. 제거 프로그램 포함·설정의 정적 확인과 실제 제거 실행 검증은 구분하며, 실제 실행 여부는 릴리스 기록을 따릅니다.

개발 검사는 `MOTOR_LAB_DATA_DIR`의 절대 경로로 분리된 프로필을 지정할 수 있습니다. `MOTOR_DESKTOP_EXE`는 이미 생성된 독립 실행 파일의 절대 경로를 지정할 때만 사용합니다. 이 변수들은 일반 사용에 필요하지 않습니다.
