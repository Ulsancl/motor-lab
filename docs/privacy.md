# 개인정보와 로컬 파일

Motor Lab은 계정·분석·광고·원격 저장 서비스를 연결하지 않습니다. 설치 앱은 HTTP(S) 요청을 차단하고 로컬 번들만 표시합니다. 사용자가 저장하는 실험 JSON과 자동 저장은 이 기기에 남습니다. 개발 의존성 설치나 공식 문서 링크를 별도 브라우저에서 여는 동작은 앱 실행과 다릅니다.

자동 저장에는 물리 상태, 관찰 화면, 카메라, 그래프, 비교 이름이 들어갑니다. 이름에 개인 정보를 적으면 파일을 공유할 때 함께 전달됩니다. 개발·오류 진단 파일에는 설치 경로, 장치·GPU 정보 또는 화면 내용이 포함될 수 있으므로 공유 전에 검토하세요. 원문 보호용 백업과 창 설정은 앱 프로필에 남을 수 있습니다. 삭제 전에 필요한 실험을 내보내세요.
