# 저장과 복원

Motor Lab 프로젝트는 `motor-lab-project`, 스키마 1, 모형 `motor-dc-average-1`을 명시한 JSON입니다. 현재 전압·부하·고정축 여부·모형 시간·전류·각속도·회전각·누적 에너지를 그대로 보관합니다. 재생 배율, 구조 레이어, 선택 부품, 카메라, 현재 그래프와 비교 기록도 포함합니다. 재생 중 여부와 안내 진행은 저장하지 않으며 불러온 실험은 일시정지 상태로 관찰합니다.

그래프는 현재 표본을 포함한 최대 1000개 기록입니다. 초기 응답과 설정 변경 지점·최신 상태를 우선하고, 한도 안에 들어오도록 중간 표본을 간소화할 수 있습니다. 단순히 최근 1000프레임만 보관하는 창이나 무제한 원시 기록이 아닙니다. 각 표본은 시간, 전류, 각속도, 역기전력, 전압, 부하 계수로 구성됩니다. 시간이 역행하거나 현재 시간 이후인 기록, 모형 범위를 벗어난 수치, 현재 상태와 다른 마지막 표본은 거부합니다. 남은 표본의 수치나 시각을 임의로 고쳐 과거 기록을 만들지 않습니다. 비교 기록은 이름·전체 모형 상태·자체 그래프를 따로 보관합니다. 표본 검증이 실제 실측의 진위를 입증하지는 않습니다.

표본 간격은 화면 프레임 수가 아닌 모형 시간으로 정합니다. 조건 변경 후 첫 20 ms는 0.5 ms, 다음 100 ms는 2 ms, 이후는 20 ms 격자를 사용합니다. 가져온 시점·설정 변경점과 최신 실제 상태도 보관합니다. 긴 단일 전진에서는 중간 표본을 최대 900개로 선택하고, 누적 상한을 넘으면 오래된 일반 표본부터 줄입니다. 보존할 기준점만 1000개를 넘으면 최초 한 개와 최근 999개 기준점을 남깁니다. 따라서 오랜 실험의 모든 과도응답 세부값이 남는 것은 아닙니다.

안내 완료 카드는 완료 시점의 상태와 안내 기준을 세션 안에서 따로 보관합니다. 현재 비교 기록을 다시 지정해도 완료 증거는 유지됩니다. 새 실험이나 파일 열기 이전의 상태를 되돌릴 때에는 안내 증거도 함께 복원하지만, 안내 진행·완료 증거 자체는 프로젝트 JSON에 넣지 않습니다.

읽기는 수치를 자동 보정하지 않습니다. 알 수 없는 필드·버전·부품, 잘못된 에너지 관계, 10 MiB 초과 파일은 현재 실험과 원문을 바꾸지 않고 거부합니다. Windows UTF-8 BOM 한 개는 허용합니다. 브라우저 자동 저장 키는 `motor-lab-project-v1`입니다. 손상되거나 새 버전인 원문을 읽으면 기존 키를 덮어쓰지 않고 원문 내보내기를 제공하는 것이 UI의 복구 계약입니다. 현재 작업은 별도 파일로 보관하세요.

설치 앱은 브라우저와 같은 검증기로 파일을 확인한 뒤 읽습니다. 저장은 같은 폴더의 임시 파일을 완전히 쓰고 디스크에 반영한 다음 이름을 바꿉니다. Windows의 일시적 파일 공유 오류는 총 775 ms의 대기를 포함해 최대 6회 교체를 시도합니다. 매 시도에서 일반 파일·실제 부모 경로를 재확인하며, 기존 목적지를 먼저 삭제하지 않습니다. 실패 시 생성한 임시 파일을 정리하고 오류를 표시합니다. 파일 작업 도중 전원 차단이나 디스크 고장까지 복구를 보장하지는 않습니다.
